# 粒级混合谱（Grain-size Mixing Spectrum）

沉积物样品常常**同时**拥有两套粒度数据：

- 筛分法给出的**质量**区间（sieve，左闭右开箱，末端含 pan）；
- 激光粒度仪给出的**体积**分布（laser，光学反演口径，检出限与箱边界不同）。

本服务把两类原始“箱”分布在明确的转换假设下投影到**共同对数粒径网格**，
对用户可定义的端元库做**非负线性混合反演**，并在端元近线性相关时保留
**多组稀疏候选、候选解簇与可识别性诊断**，而不是只给一个小数位稳定的唯一比例。

技术栈：Kotlin + Ktor(CIO) + SQLite(xerial JDBC) + 原生 Web UI（无外部前端依赖）。

## 快速开始

```bash
# 安装打包（跳过测试）
mvn -q -DskipTests package

# 演示：测试 + 启动本地服务
mvn -q test && mvn -q exec:java -Dexec.mainClass=app.MainKt -Dexec.args='--port 5568'
```

打开 <http://127.0.0.1:5568>，页面标题应为 **粒级混合谱**。

可选参数：`--db=path/to/grainmix.db`（默认 `data/grainmix.db`），或环境变量 `GRAINMIX_DB`。
首次启动且端元表为空时，自动写入随包的**固定 fixture**。

## 数据口径与转换假设（每次求解固定并记录）

1. **箱约定**：每个分布用 `edges`（长度 = `values.size + 1`）与箱内积分量 `values`（克、体积份数等，
   **非密度**）表示。第 i 箱为 `[edges[i], edges[i+1])`，**左闭右开**；
   **最后一箱的右端点 `edges.last()` 单独声明**（例如筛分 pan 的右端点 4000 μm）。
   区间分配只按相交段 `(max(l,a), min(r,b))`，端点相接不产生重复质量。
2. **共同网格**：`log10(d)` 等距，用户固定 `minD / maxD / binsPerDecade`；
   跨度非整数倍时箱数上取整、余宽均摊，首末端点精确等于声明值。
3. **箱内分布**：每个原始箱内在 `ln(d)` 上均匀（log-uniform within bin）。
4. **口径（权重）转换**：等球径矩模型 `SPHERICAL_MOMENT`——数量 `d^0`、面积 `d^2`、
   体积与质量 `d^3`；质量 = ρ×体积（密度 ρ 用户固定，默认 2.65 g/cm³）。
   公共形状因子（π/6 等）在比例反演中消去。数量/面积口径下按相应粒径矩逐相交段积分。
5. **折射率**：激光体积视为已按该折射率完成光学反演；折射率 n（默认 1.54）作为
   **固定假设随每次求解记录**，不做二次 Mie 修正。
6. **总量守恒（不归一化失量）**：对每台仪器分别记账
   `源总量 = 网格内 + 网格下失量 + 网格上失量`（源口径与目标口径各一份），
   页面与 API 均显示守恒差；**网格外未覆盖量只记账、不并入网格箱、不归一化掉**。
7. **仪器合并**：多台仪器在统一目标口径后，按覆盖箱做 `MEAN`（默认，覆盖均值）/
   `SUM` / `FIRST` 合并；未覆盖箱不进入反演行。

## 反演与可识别性

测量模型 `y = A c, c ≥ 0`，A 的列为端元在网格覆盖行上的分布（统一口径，保留各自总量）。

- 候选族由**确定性、可复现**的三部分生成：全端元加权 NNLS（Lawson–Hanson 主动集）、
  全部列子集（规模 ≤ `maxSubsetSize`）的非负最小二乘、Lasso 坐标下降路径；
- 权重来自端元相对标准差与指数相关长度合成的测量协方差（Cholesky 白化），
  端元可逐箱定义 `relSigma` 与 `corrLength`；
- 候选按 BIC（含稀疏惩罚）排序，按支持集分组轮转，保证不同稀疏结构都能露出；
- 候选按比例欧氏距离 ≤ 0.08 聚成**解簇**；
- 诊断输出：成对余弦/Pearson 相关（|cos|≥0.985 标记近线性相关）、
  设计矩阵条件数量级、前若干候选的比例展布（profile spread）、首二候选加权 RSS 间隔。

当端元近相关时（fixture 中“粉砂 E_SILT”与“细砂 E_FINESAND”余弦 ≈ 0.996），
页面会同时展示 `{粗砂,细砂}`、`{粗砂,粉砂}` 等多个稀疏候选与解簇，并提示比例不可唯一辨识。

## 固定 fixture

- 端元：`E_SAND`（粗砂，中值 450 μm）、`E_SILT`（粉砂，62 μm）、
  `E_FINESAND`（细砂，66 μm；与粉砂近线性相关），均为质量口径对数正态。
- 样品 `S_MIXED`：
  - 筛分 `sieve`：0.063–4000 μm（pan 右端点单独声明），质量口径；
  - 激光 `laser`：0.3–600 μm，34 个对数箱，体积口径；
  - 两套边界与共同网格 [1, 2000] μm（8 箱/十倍程）**不完全重叠**，
    筛分 pan 产生网格上失量，激光/筛分细尾产生网格下失量。

## 运行记录导出 / 清空 / 重新导入复核

- 页面“导出运行记录(JSON)”或 `GET /api/export` 下载整包（端元 + 样品 + 全部运行）。
- `POST /api/import` 在**单事务**内先清空再写入整包；可先“清空数据库”
  （删除 `data/grainmix.db*` 或调用导入覆盖）后重新导入。
- 对任一运行 `POST /api/solves/{id}/replay`：用存档请求重新求解，
  与存档结果逐字段比较，返回 `matched` 与 `maxAbsDiff`（反演确定性，应为 0）。
- `POST /api/reset` 清空业务表并恢复固定 fixture。

## HTTP API 摘要

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/health` | 健康检查 |
| GET/POST/DELETE | `/api/endmembers[/{id}]` | 端元库（分布与协方差） |
| GET/POST/DELETE | `/api/samples[/{id}]` | 样品（多仪器原始箱） |
| GET | `/api/solves[/{id}]` | 运行记录列表/详情 |
| POST | `/api/solve` | 求解（固定网格、折射率、密度假设）并保存 |
| POST | `/api/solves/{id}/replay` | 确定性重放复核 |
| GET/POST | `/api/export` `/api/import` | 整包导出/导入 |
| POST | `/api/reset` | 清空并恢复 fixture |

## 自动化测试

`mvn -q test` 覆盖：投影守恒、左闭右开/末箱端点、边界相接不重复、
体积→质量密度换算、数量→质量粒径矩、网格外失量不归一化、近相关多候选与解簇、
合成混合比例恢复、以及端到端 HTTP（首页标题、求解、导出→清空→导入→重放一致）。
